# AI智能体搭建功能使用说明书

## 一、功能简介

AI智能体搭建是企业AI一站式平台V3.0的核心功能，提供两种智能体类型满足不同业务场景：

### 1.1 简易智能体
适合快速部署的基础问答场景，具备：
- 系统提示词配置
- 知识库关联（自动检索相关文档）
- 回答风格选择（简洁/详细/友好/专业）
- 访问密码保护（可选）

### 1.2 高级智能体
适合复杂业务逻辑场景，具备：
- 敏感词过滤（安全拦截）
- 问题优化（意图识别+语义补全）
- 知识库检索增强
- 执行记录追溯

## 二、快速开始

### 2.1 登录系统
1. 打开浏览器访问：http://localhost:5173
2. 输入账号密码登录（默认admin/123456）
3. 进入首页后，左侧菜单找到「AI智能体搭建」

### 2.2 创建第一个简易智能体

**步骤1：进入管理页面**
- 点击菜单「AI智能体搭建」→「简易智能体」

**步骤2：新建智能体**
- 点击右上角「新建智能体」按钮
- 填写基本信息：
  - **智能体名称**：如"客服助手"
  - **角色设定**：描述智能体的职责，如"你是一个专业的电商客服助手"
  - **系统提示词**：定义智能体的行为模式，如"请用简洁友好的方式回答用户问题，如果不确定请告知用户"

**步骤3：配置知识库（可选）**
- 点击「关联知识库」下拉框
- 搜索并选择相关文档（如产品手册、常见问题等）
- 关联后，智能体会自动检索相关知识库内容回答问题

**步骤4：选择回答风格**
| 选项 | 说明 | 适用场景 |
|------|------|----------|
| 简洁 | 简短直接的回答 | 快速查询 |
| 详细 | 完整详细的回答 | 知识科普 |
| 友好 | 亲切友好的语气 | 客服接待 |
| 专业 | 正式专业的表述 | 技术支持 |

**步骤5：其他配置**
- **温度参数**：0=确定性高，1=创造性高（建议0.7）
- **最大Token**：回答最长长度（建议2048）
- **显示引用**：开启后回答中会显示参考的文档来源
- **访问密码**：如需限制访问可设置密码

**步骤6：保存启用**
- 点击「确定」保存
- 新智能体默认启用状态

## 三、核心功能操作指南

### 3.1 简易智能体管理

#### 列表查看
- 支持按名称搜索
- 显示关联文档数、回答风格、状态等信息
- 分页查看（每页10条）

#### 编辑智能体
1. 在列表中找到目标智能体
2. 点击「编辑」按钮
3. 修改配置项
4. 点击「确定」保存

#### 启用/禁用
- 已启用的智能体：点击「禁用」按钮
- 已禁用的智能体：点击「启用」按钮
- 禁用的智能体无法进行对话

#### 删除智能体
1. 点击「删除」按钮
2. 确认删除操作
3. 系统会自动清理相关执行记录

### 3.2 高级智能体管理

#### 基础配置
与简易智能体类似，额外支持：
- **工作流描述**：描述智能体的工作逻辑
- **入口问题预设**：预设用户可能提问的问题（每行一个）
- **问题优化**：开启后自动优化用户提问
- **敏感词过滤**：开启后拦截违规问题
- **敏感词列表**：用逗号分隔的敏感词

#### 工作流节点（预留功能）
当前版本预留了工作流节点配置接口，后续版本将支持：
- 输入节点 → 判断器节点 → LLM节点 → 知识库检索节点 → 函数调用节点 → 输出节点

## 四、智能体对话使用

### 4.1 测试对话
1. 进入智能体管理页面
2. 点击智能体名称进入详情（或在新版本中会有测试入口）
3. 输入问题进行测试

### 4.2 调用API
```bash
# 简易智能体对话
curl -X POST http://localhost:8080/api/v1/agent-builder/simple/chat/1 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"question": "你们的产品有哪些？"}'

# 高级智能体对话
curl -X POST http://localhost:8080/api/v1/agent-builder/advanced/chat/2 \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{"question": "订单状态查询"}'
```

### 4.3 带密码访问
```json
{
  "question": "用户问题",
  "password": "访问密码"
}
```

## 五、执行记录查看

### 5.1 进入记录页面
- 菜单「AI智能体搭建」→「执行记录」

### 5.2 筛选查看
- **智能体筛选**：查看特定智能体的记录
- **类型筛选**：按简易/高级智能体筛选
- **时间范围**：默认显示最近记录

### 5.3 记录信息
每条记录包含：
- 智能体类型（简易/高级）
- 用户问题
- AI回答（鼠标悬停查看完整内容）
- 耗时（秒）
- 时间戳

## 六、常见问题解答

### Q1: 知识库关联后如何生效？
A: 关联知识库后，智能体对话时会自动进行向量检索，提取相关文档片段注入Prompt。确保知识库文档已完成向量化处理（在知识库管理页面点击「重新向量化」）。

### Q2: 敏感词过滤不生效？
A: 检查：
1. 敏感词过滤开关是否开启（enableSafety=1）
2. 敏感词列表是否正确配置（逗号分隔）
3. 用户问题是否包含配置的敏感词

### Q3: 问题优化功能如何工作？
A: 开启问题优化后，系统会调用LLM对用户问题进行意图识别和语义补全，返回优化后的问题再进行后续处理。例如：
- 用户问："价格" → 优化为："请问你们产品的价格是多少？"

### Q4: 访问密码如何设置？
A: 在创建/编辑简易智能体时，「访问密码」字段留空表示不设置密码，填写后调用对话接口必须传入正确密码。

### Q5: 执行记录会保留多久？
A: 当前版本永久保留。后续可考虑定期清理策略。

### Q6: 温度参数如何影响回答？
A: 
- 0.0-0.3：回答稳定、可预测，适合事实性问题
- 0.4-0.7：平衡创造性和准确性，适合通用场景
- 0.8-1.0：回答更具创造性，适合创意生成

### Q7: 知识库文档如何选择？
A: 建议选择与智能体职责高度相关的文档，单个智能体建议关联10-20个文档，过多会影响响应速度。

## 七、最佳实践建议

### 7.1 简易智能体配置建议
- **系统提示词**：清晰定义角色、职责、回答风格
- **知识库关联**：选择相关性高的文档，避免关联过多文档影响性能
- **回答风格**：客服场景建议用"友好"，技术支持建议用"专业"
- **温度参数**：客服场景建议0.3-0.5，创意场景建议0.7-0.9

### 7.2 高级智能体配置建议
- **敏感词列表**：定期更新，覆盖最新风险词汇
- **问题优化**：复杂业务场景建议开启，简单场景可关闭以提升性能
- **知识库检索**：结合问题优化使用效果更佳

### 7.3 性能优化建议
- 知识库文档数量控制在合理范围（建议单个智能体关联20个以内文档）
- 执行记录定期清理（超过6个月的记录可归档）
- 并发对话建议限制（生产环境建议配置限流）
